# 섹터 최근 60분 경로 분석

적용 버전: `expert-placeholder-v4-sector-hourly-path`.
대상은 오늘 섹터 흐름 및 장중·오버나이트 분석의 섹터 판정이다.
다른 스캐너, 실행 시간표, 기존 개별 종목 진입 지표의 5분 설정은 변경하지 않는다.

## 구간과 품질

- 평가 시작 시각 직전까지 완료된 분봉을 사용한다. 최근 60개 행이 아니라 최근 60분의 실제 시각으로 자른다.
- 종목과 코스피의 동일한 분을 맞추며 누락된 분봉을 보간하거나 전날 데이터로 채우지 않는다.
- 첫 봉과 마지막 봉이 있고, 동일 시각 분봉이 예상 분 수의 90% 이상이며 3분 초과 간격이 없어야 한다.
- 개장 후 20분 미만은 자료 부족, 20~59분은 잠정이다. 잠정 결과로 확정 강세나 진입 허용을 만들지 않는다.
- 추적 섹터 종목의 80% 이상이 자료 조건을 충족해야 하며, 기존 최소 4종목·조건별 최소 3종목 기준도 적용한다.
- 동시호가를 제외해 15:20 이후에는 14:20~15:19의 연속매매 흐름을 사용한다. 기존 동시호가/종가 신호는 별도로 유지한다.

## 분봉 경로에서 평가하는 네 조건

1. VWAP 지지: 각 분 종가가 **그 분까지**의 구간 누적 VWAP 위에 있는 비율 >=60%, 마지막 가격도 구간 VWAP 이상. 가격은 `(고가+저가+종가)/3`으로 거래량 가중한다. 미래 봉으로 과거 지지를 판정하지 않는다.
2. 상대강도 유지: 구간 첫 분의 시가를 기준으로 매 분 종목 수익률에서 같은 시각 코스피 수익률을 뺀다. 양수인 분 비율 >=60%이고 마지막 초과수익률도 양수여야 한다.
3. 가격 구조: 모든 분봉 종가의 시간당 추세 기울기 >0, 10분 블록별 최저가가 높아지는 비교 비율 >=60%, 최고가에서 상승폭 반납 <=50%. 각 블록에 8개 이상 분봉이 있어야 저점 비교에 포함한다.
4. 거래 흐름: 직전 분보다 오른/내린 분의 `종가×거래량`을 각각 합산해 상승 구간 비중 >=55%, 구간 수익률 >0. 이전 60분도 충분하면 분당 거래대금 근사치가 감소하지 않아야 한다. 이전 구간이 없으면 증감은 결측으로 표시하고 방향별 거래 비중만 사용한다. 이는 실제 매수/매도 체결량이나 순매수가 아니다.

각 조건을 만족하는 종목 비율을 섹터 내에서 집계한다. 표시 단계는 네 조건의 최솟값이 각각 40/50/60%일 때 후보/확산/진짜 강세이다. 실제 판정의 자료 부족·집중도 경고·차단 조건을 화면 단계가 덮어쓰지 않는다. VWAP과 가격 구조는 같은 가격 계열이므로 회피 판정에서 독립된 두 실패로 중복 계산하지 않는다.

수치는 전문가 시작용 규칙이며 수익성 검증이나 학습으로 확정한 값이 아니다.

## 수집과 저장

종목당 최대 5페이지, 필요한 최근 약 120분만 추가 요청한다. 같은 페이지 반복·오류·진행 없음이면 중단한다. 최초 30개 응답은 기존 진입 신호에 그대로 사용하며 확장 응답은 섹터 분석에만 사용한다. 구간별 요약, 데이터 충족도와 판정 근거를 기존 실행 결과 JSON에 저장한다. 추가 원시 분봉 테이블을 생성하거나 분석 주기를 늘리지 않는다.

과거 기록은 기존 단기 기준으로 남는다. 과거 30분 자료를 60분 결과라고 바꾸지 않는다. 전체 당일 분봉이 없는 경우 당일 누적 VWAP을 추정하지 않고 결측으로 남긴다.

## 검증

같은 끝점·다른 경로, 급등 후 반납, 개장 초기, 누락·중복·희소 분봉, 전일·미래 봉, 시각 불일치, 거래량 0, 직전 60분 비교, 동시호가 제외, 기존 30개 응답 보존, 확정/잠정 화면을 자동 테스트한다.
실제 KIS 읽기 전용 점검에서 2026-09-11 삼성전자와 코스피의 14:20~15:19 시각 일치 60개를 확인했다. 이는 단일 시점 수집 검증이며 미래 모든 실행의 성공이나 전략 수익성을 보장하지 않는다.
