# Phase 3 파생값·신호 생성 현황

작성일: 2026-08-01
상태: 오프라인 구현 및 경계 테스트 완료

## 구현

- `features.py`
  - 정규화된 `Observation`에서 종목·지수·선물 분봉 복원
  - 당일 VWAP과 종가의 VWAP 이격률
  - 봉 CLV 및 CLV 가중 거래대금 Proxy
  - 동일 설정 구간의 단기 수익률과 벤치마크 대비 상대수익률
  - 직전 구간 대비 거래 활동 속도 변화
  - 14:30~15:00, 15:00~15:20, 15:20~15:30 마감 구간 분리
- `signals.py`
  - 가격 행동, 실제 프로그램 수급, 선물 가격 확인, 상대강도, 활동 축 생성
  - VWAP과 CLV Proxy를 동일한 `price_action` 축으로 유지
  - CLV Proxy 문구에 실제 순매수가 아님을 명시
  - 거래 활동 증가가 하락과 함께 나타나면 반대 증거로 처리
  - 섹터 구성 종목을 동일가중 방식으로 집계
- `pipeline.py`
  - 관측값과 섹터 구성표로 시장·섹터·종목 파생값과 신호 일괄 생성
  - 누락 종목을 `missing_instruments/missing_members`로 반환
  - 시장 지수 시계열이 없으면 값을 만들어내지 않고 실행 중단
- `config.py`
  - 버전이 있는 JSON 설정 로더
  - 알 수 없는 설정 필드와 잘못된 경계값 즉시 거부
- `config/market_betting_engine.placeholder.json`
  - 현재 전문가 휴리스틱 임계값을 `placeholder: true`로 외부화

## 독립 축 원칙

다음 둘은 같은 가격봉에서 계산되므로 독립 축 두 개로 세지 않는다.

```text
VWAP 가격 구조 ─┐
                ├─ price_action 1개 축
CLV Flow Proxy ─┘
```

기본 시장 평가가 가능한 최소 조합은 다음과 같다.

```text
price_action + actual_flow + futures
```

Breadth가 연결되면 별도의 `participation` 축으로 추가할 수 있다. 선물 가격 확인은 베이시스 신호로 표현하지 않는다.

## 검증

총 71개 테스트 통과.

- 거래량 0 VWAP
- Flat bar CLV
- 상승·하락 활동 가속의 방향 구분
- 실제 프로그램 수급과 가격 Proxy 분리
- 같은 축 신호 중복으로 최소 축 조건을 충족하지 못하도록 차단
- 마감 3구간 경계
- 섹터 누락 종목 공개
- 설정 버전 및 알 수 없는 필드 차단

## 아직 확정하지 않은 것

- 임계값은 백테스트 최적값이 아니라 전문가 초깃값이다.
- 프로그램 금액 단위가 `VERIFIED` 전이므로 실데이터 판단은 계속 `NOT_EVALUABLE`이다.
- 선물 베이시스·미결제약정 결합 해석은 장중 필드 검증 후 추가한다.
- 시장 전체 Breadth는 공식 요청 계약 확인 전까지 생성하지 않는다.
