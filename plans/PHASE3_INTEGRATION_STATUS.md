- Read-Only 프로브 원문을 디스크에 추가 저장하지 않는 인메모리 연결
- 공통 품질 게이트→시장→섹터→종목 실행 순서 구현

## 현재 안전 상태

실제 API 응답은 아직 모두 `PARTIAL`이다. 따라서 화면이나 진단에는 표시할 수 있지만, 기본 오케스트레이터에서는 다음 결과를 낸다.

```text
FIELD_SEMANTICS_PARTIAL → DataQuality BLOCKING → NOT_EVALUABLE
```

필드 단위와 장중 의미를 확인해 `VERIFIED`로 명시적으로 올리기 전에는 `ALLOW` 또는 `TRIGGERED`를 생성하지 않는다.
